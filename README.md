# Etsy Market Research Tool

A personal market research tool for analyzing publicly available Etsy listings by keyword.

This tool is intended to support product research for print-on-demand products such as T-shirts.

## Purpose

The tool helps analyze Etsy listing data such as:

- Listing titles
- Prices
- Listing counts
- Favorites
- Shop information
- Product URLs

The collected data is used to compare product niches, pricing ranges, and competition levels.

## Usage

This application is for personal or internal use only.

The data collected through Etsy's API will not be resold or redistributed.

## Technology

- Python
- Etsy Open API v3
- pandas
- openpyxl

## Planned Features

- Keyword-based listing search
- Market competition analysis
- Price analysis
- Excel export
- Niche comparison
- Product research for print-on-demand items
